# Olá, eu sou o Diogo 👋

**Full Stack · Backend · Dados · IA · IoT e Automação — Lavras, MG.**

Entusiasta de tecnologia e desenvolvimento de software, trabalhando **do dispositivo à aplicação**: IoT, coleta de dados, telemetria, APIs, backend, dashboards e IA aplicada.

Construo soluções que conectam o mundo físico ao digital — desde Arduino, sensores e dispositivos conectados, passando por APIs e processamento de dados, até dashboards, automações e interfaces inteligentes.

## O que eu faço

- **Backend:** Laravel, PHP, Python, Node.js e APIs REST
- **Frontend:** TypeScript, React, Next.js e Bootstrap
- **Dados:** SQL Server, PostgreSQL, MySQL, ETL e Power BI
- **IA e automação:** agentes, LLMs, NL2SQL e n8n
- **IoT e infraestrutura:** Arduino, sensores, telemetria, Docker, Linux e CI/CD

## Projetos

- **[Orbital](https://github.com/DiogoWallace/orbital):** projeto voltado à astronomia e análise de dados de observações espaciais.
